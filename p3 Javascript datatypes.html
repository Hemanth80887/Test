Javascript datatypes

There are 2 types of datatypes in javascript

1) Primitive datatypes

2) Non-Primitive datatypes

    Primitive datatypes

  1. String datatypes - (char or word)
  2. Number datatype (Int or float)
  3. BigInt datatype
  4. Undefined Datatype
  5. Null Datatype

    Non-primitive datatype

  1. Array (arrays is used to containe the multiple values creating by using [])
  2. Object (object is a series of properties property = key:value create by using {})
  3. Function (it is used to store the code thats why we are calling function is a block of code to execute later using name of the function we can create by using function keyword )
